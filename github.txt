	1. -------------------- Проверяем задан ли пользователь --------------------
		git config --get user.name
		git config --get user.email
	
	2. -------------------- Если пользователь не задан --------------------
		git config --add --global user.name 'github_user_name'
		git config --add --global user.email 'github_user_email'

	-------------------- Создание репозтории и добавление --------------------

		git init
		git add README.md		
		git commit -m "first commit"
		git branch -M main
		git remote add origin https://github.com/VladimirKonstantinovich/-.git
		git push -u origin main


	-------------------- Добавление в существующую репозторию --------------------

		git remote add origin https://github.com/VladimirKonstantinovich/-.git
		git branch -M main
		git push -u origin main
